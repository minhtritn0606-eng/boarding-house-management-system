# 🏠 Boarding House Management System

> A cross-platform boarding house management and room rental platform.

## 📖 Introduction

Boarding House Management System is a cross-platform application that helps landlords manage boarding houses while providing a website for users to search for rental rooms.

The project consists of:

- 🌐 Website for searching rental rooms.
- 📱 Mobile application for landlords to manage boarding houses and tenants.
- ⚙️ RESTful API Backend.
- 🗄️ MySQL Database.

---

## 🎯 Objectives

- Simplify boarding house management.
- Help users easily search for rental rooms.
- Centralize data between Website and Mobile App.
- Provide a modern, scalable architecture.

---

## 👥 User Roles

### Visitor
- Browse available rooms
- Search by location
- Filter by price
- View room details
- View Google Maps location

### Landlord
- Login securely
- Manage boarding houses
- Manage rooms
- Manage tenants
- Manage rental contracts
- Manage utility bills
- Send notifications
- View dashboard statistics
